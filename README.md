# Sonith downloads

Installers for **Sonith**, a desktop app that takes any song apart into vocals, drums, bass and the rest, on your own
computer. The app's source code is private; this repository only holds the installers, under
[Releases](https://github.com/Xtendr/sonith-downloads/releases).

These are early personal builds, shared with friends. They are not signed by Apple or Microsoft yet, so your computer
asks once before it opens them.

## Mac (Apple silicon: M1 or newer)

1. Download `Sonith-mac.zip` from the latest release and open it. Drag **Sonith** into **Applications**.
2. Open Sonith. macOS says it can't verify the app: click **Done**.
3. Open **System Settings → Privacy & Security**, scroll down to the message about Sonith and click **Open Anyway**.
   Confirm once. From then on it opens normally.

On first use Sonith downloads its separation models from their authors. Your songs never leave your Mac.
